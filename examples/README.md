# Examples

The tutorials and guides moved to the documentation: they are jupytext notebooks
(`.py`) in [`docs/tutorials/`](../docs/tutorials) and [`docs/guides/`](../docs/guides),
rendered with their outputs at [schnetpack.readthedocs.io](https://schnetpack.readthedocs.io).
[Contributing](../docs/contributing.md) explains how to run one as a notebook.

This folder keeps what the notebooks use:

| Folder | Content |
| --- | --- |
| `trained_models/` | five PaiNN models of ethanol (rMD17), used by the guide [Ensembles and Uncertainty](../docs/guides/ensembles_uncertainty.py) |
